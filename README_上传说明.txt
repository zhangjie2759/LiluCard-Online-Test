利禄卡 Online v4.2 资源调用清理版

这版继续基于 v3.9 / v4.1，不改 index、viewport、canvas 布局，避免破坏 UI。

重点修复：
1. “你的回合...”提示：
   - 中间框不再显示底部提示条。
   - 只保留餐段标题和警戒线。
   - 自己回合通过底部按钮状态表达。
   - 对方回合仍然用浮层“对方点餐中”提示。

2. 图片加载逻辑清理：
   - 失败图片不再永久缓存。
   - 图片只缓存成功或正在加载的状态。
   - 失败后短暂冷却，再由当前画面自动重新请求。
   - 不再维护复杂 attempts / retryTimers 状态。
   - 保持原始路径 img.src = src，不加 ?v，不用 decode。

3. 占位图更干净：
   - 图片未加载时显示轻量占位。
   - 不再显示“重试中”等干扰信息。

4. 保留所有功能：
   - 单机
   - 联机
   - 准备/开房间/加入房间
   - 夜宵
   - 小局结算
   - 今日结算
   - 音乐按钮
   - 顶部按钮最上层

不包含 audio 文件夹。

上传到 GitHub 仓库根目录，替换：
- index.html
- game.js
- online.js

继续保留：
- images/cards
- 如果需要音乐，请你自己保留 audio/bgm.mp3
