利禄卡 Online v2.7 联机同步防卡住版

这版重点修复“我明明选牌了，对方迟迟看不到，导致卡住”的问题。

主要原因：
之前每次操作会把整个 game 对象写回数据库。
如果双方在“起手阶段 / 夜宵阶段 / 进入下一局确认”几乎同时操作，
后写入的一方可能会用旧快照覆盖掉另一方刚写入的手牌或确认状态。
结果就是：一方明明抽牌了，另一方看不到，流程卡住。

v2.7 修复方式：
1. 普通抽牌/收手时，只写入“自己的玩家状态”和自己的记录，不再整包覆盖。
2. 双方同时抽起手牌时，不会互相覆盖手牌。
3. 夜宵双方同时选择时，不会互相覆盖夜宵选择。
4. 进入下一餐的双方确认状态，不会互相覆盖。
5. 每次自己写入后，会立刻重新读取最新房间，自动判断是否进入：
   - 正式点餐阶段
   - 夜宵展示阶段
   - 小局结算
   - 下一餐
   - 下一整局
6. 加入短时间本地写入保护，减少“刚抽出的卡又闪没”的情况。
7. 轮询间隔略微加快到 200ms。
