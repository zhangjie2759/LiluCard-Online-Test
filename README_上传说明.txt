利禄卡 Online v2.0 稳定流程版

这版不是继续补丁，而是按“状态机”重新整理流程：

1. 首页：单机游戏 / 开房间 / 加入房间
2. 联机大厅：双方准备后才开始
3. 起手阶段：双方各抽2张，不分先后
4. 早餐：起手完成后随机先手
5. 午餐：自动换另一方先手
6. 晚餐：换回早餐先手方
7. 点餐阶段：明确显示“你的点餐回合 / 对方点餐回合”
8. 双方结束后自动进入本餐结算
   - 收手算结束
   - 爆牌也算结束
9. 本餐结算页会显示：
   - 对方点了什么外卖
   - 我方点了什么外卖
   - 双方本餐热量
   - 是否爆牌
   - 组合奖励
   - 当前小局比分
10. 夜宵不分先后，双方选完后自动揭晓并结算
11. 最后进入今日总结算
