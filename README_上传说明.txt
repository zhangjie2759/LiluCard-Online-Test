利禄卡 Online v2.3 稳定体验修复版

根据反馈修复：
1. 降低联机延迟：轮询从 250ms 更新，并加入本地 actionSeq 保护，避免旧快照覆盖新状态。
2. 优化卡牌显示速度：加入卡牌图片预加载，并将图片加载后的 render 改为节流渲染，减少闪烁。
3. 今日结算新增明确胜负：
   - 赢的一方显示“恭喜你赢了！”
   - 输的一方显示“你输了”
4. 底牌显示修复：
   - 自己可以看到自己的底牌
   - 对方区域的底牌显示为牌背
5. 小局结算页增加中间摘要：
   - 本餐你赢/你输/平局
   - 本餐双方卡路里
   - 本餐点数
   - 累计小局比分
6. 进入下一餐需要双方都确认：
   - 你点确认后会锁定为“已确认”
   - 双方都确认后才进入下一餐/今日结算
7. 游戏结束后不会退出房间：
   - 停留在今日结算页
   - 双方点击“准备下一局”后，在同一房间开始下一整局
