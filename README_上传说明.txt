利禄卡 Online v2.6 夜宵展示与提示修复版

根据反馈修复：
1. 开局后的“开始 / 双方已准备”遮罩不再持续显示。
   - 只在准备阶段允许出现。
   - 一旦进入起手阶段就隐藏。

2. 删除“轮到你点外卖”的红色提示。
   - 自己回合不再额外弹红字。
   - 只保留对方回合的明确等待提示。

3. 夜宵不会自动进入结算。
   - 双方选完夜宵后，进入“展示夜宵”阶段。
   - 需要点击“展示夜宵”按钮，才会揭晓并结算。
