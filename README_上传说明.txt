利禄卡 Online v2.8 首页与结算UI优化版

根据反馈优化：
1. 单机模式增加“首页”按钮，可以随时返回主界面。
2. 首页 UI 优化：
   - 开房间 / 加入房间改成左右并排。
   - 游戏规则放进上方大框里。
   - 点击“查看游戏规则”后，大框切换成规则内容。
   - 规则内容支持上下滑动。
3. 游戏规则改为完整流程版，简洁说明联机流程、起手、点餐、爆牌、夜宵和结算。
4. 所有按钮加入点击反馈：按下时轻微放大再还原。
5. “对方点餐回合，请等待对方操作”的红字取消，保留更清楚的浮动提示框。
6. 小局结算页大幅简化：
   - 只保留当前是哪一餐。
   - 本餐你赢 / 你输 / 平局。
   - 当前比分。
   - 加一句嘲讽/夸奖文案。
7. 警戒线改为进度条，越接近警戒线填充越满，接近时变橙，爆牌变红。
