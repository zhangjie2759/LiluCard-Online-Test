利禄卡 Online v2.4 信息隐藏与流程提示修复版

根据反馈修复：
1. 对方当前局信息隐藏：
   - 你不能提前知道对方是否爆牌
   - 你不能提前知道对方这一把具体热量
   - 对方当前局卡牌在结算前显示为牌背
   - 结算页才公开双方具体外卖和热量

2. 爆牌后仍然可以继续叫外卖：
   - 爆牌不再自动结束
   - 玩家可以继续点外卖迷惑对方
   - 只有主动收手才算结束
   - 双方都收手后才进入本餐结算

3. 下一整局开始不再弹“双方已准备，开始下一局”
   - 双方准备后直接进入起手阶段
   - 起手阶段文案改成双方可以同时抽2张
   - 如果你抽完，对方没抽完，会显示“等待对方出牌”

4. 等待对方叫外卖提示更明确：
   - 中间提示写“对方点餐回合”
   - 底部按钮上方也会显示“对方点餐回合，请等待对方操作”
   - 按钮文案显示“等待对方 / 对方点餐回合”
