利禄卡 Online v6.4 黑色出票口塔罗版

这版基于 v6.1 稳定版做最小改动：
1. 首页主视觉文案“我的嘴，就是秤。”和“单机 / 开房间 / 加入房间”整体上移。
2. 删除鸡蛋塔罗表现，改成黑色横向出票口。
3. 点击出票口后，卡牌从黑色口子里慢慢向下出票。
4. 卡牌上端被黑色出票口遮住，形成“从洞里出来”的效果。
5. 出票完成后显示：你今天适合吃 XXX。
6. 再点一次可以重置重新抽。
7. 不改联机逻辑、不改主游戏流程、不包含 audio 文件夹。

上传到 GitHub 仓库根目录，替换：
- index.html
- game.js
- online.js

如果你原来有 images/cards，请继续保留。
如果你原来有 audio/bgm.mp3，也请继续保留。
