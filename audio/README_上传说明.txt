利禄卡 Online v2.9 BGM 完整替换包

这包里包含：
- index.html
- game.js
- online.js
- README_上传说明.txt
- audio 文件夹占位说明

注意：
音乐文件不会自动生成，你需要自己准备 mp3 并上传到：

audio/bgm.mp3

路径必须完全一致：
audio/bgm.mp3

大小写也要一致，不能是：
Audio/bgm.mp3
audio/BGM.mp3
audio/bgm.MP3

上传后 GitHub 目录应为：
index.html
game.js
online.js
images/cards/...
audio/bgm.mp3

手机浏览器不会自动播放音乐。
玩家必须先点一次按钮，例如“单机游戏 / 开房间 / 加入房间”，音乐才会开始循环。

如果没有音乐，优先检查：
1. audio/bgm.mp3 是否真的上传了
2. 文件名大小写是否完全正确
3. 是否打开的是 GitHub Pages 链接，而不是 GitHub 仓库页面
4. 是否用了 ?v=30 强制刷新

测试链接示例：
https://zhangjie2759.github.io/LiluCard-Online-Test/?v=30
